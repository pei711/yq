Fixes #2994

`delpaths` currently applies array paths in input order. Deleting a lower array index shifts later elements, so subsequent paths can target the wrong items. Repeated paths can also delete a second item after the first deletion shifts the array.

Sort paths from highest to lowest (including deeper paths before their parent paths) before deleting, and skip duplicate paths. Add regression scenarios for reversed sibling order and duplicate paths.
